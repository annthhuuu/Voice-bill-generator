# GitHub Project Board

The task backlog has been created as GitHub Issues in this repository. Use this board to track each issue through the workflow.

## Create the board
1. Open the repository on GitHub.
2. Select **Projects** → **New project** → **Board**.
3. Name it **AI Voice Bill Generator – Development Board**.
4. Add a view filtered to this repository's issues.
5. Create these status columns: **To Do**, **In Progress**, **Done**.
6. Add the eight open issues listed below as board items.
7. Move an item to **In Progress** when work starts. Move it to **Done** only after the acceptance criteria are met and reviewed.

## Suggested workflow
- Keep one issue per meaningful task.
- Add screenshots, test output, and relevant commit links to issue comments.
- Close issues only after the acceptance criteria are satisfied.
- Update `progress/progress.md` whenever a milestone changes.

> Note: The issue backlog is created. The Project board itself must be created in the GitHub Projects UI because the connected GitHub actions available in this session do not expose project-board creation.
