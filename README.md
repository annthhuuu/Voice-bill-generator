# AI Voice Bill Generator

Software Engineering Lab storyboard repository.

This project explores voice-assisted bill creation: speech capture, speech-to-text, product and quantity extraction, bill calculation, review, and bill export.

See:
- `diagrams/` for requirements and design models
- `progress/` for progress, timeline, and issue tracking
- `test-cases/` for planned verification scenarios

The implementation technology stack is yet to be finalized. This README describes the proposed system, not a completed implementation.
